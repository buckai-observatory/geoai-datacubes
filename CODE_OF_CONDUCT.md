# Code of Conduct

This project adopts version 2.1 of the [Contributor Covenant], a widely used
code of conduct for open-source communities. The full text is available at:

<https://www.contributor-covenant.org/version/2/1/code_of_conduct/>

In one sentence: be respectful, assume good faith, and remember that this is
an academic project run by humans with limited bandwidth.

## Scope

This Code of Conduct applies within all project spaces, including the GitHub
repository (issues, pull requests, discussions, code review comments), the
project website, and any other space directly associated with the project.

It also applies when an individual is officially representing the project in
public spaces — for example, when using an official email address, posting via
an official social media account, or acting as an appointed representative at
an online or offline event.

## Reporting

If you experience or witness behaviour that violates the Contributor Covenant
in any project space, please contact the project's primary maintainer:

[**moortgat.1@osu.edu**](mailto:moortgat.1@osu.edu)

Reports are handled confidentially and as promptly as the maintainer's other
academic responsibilities allow. The maintainer will:

1. Acknowledge receipt of the report (target: within 5 business days).
2. Investigate the situation, with input from the parties involved.
3. Take appropriate action, which may include a private conversation, a public
   moderation note, temporary or permanent removal of comments or
   contributions, or a temporary or permanent ban from project spaces.

For situations that may also involve a violation of The Ohio State University
policy (the project's institutional home), the maintainer may additionally
direct or refer the report to the relevant OSU office.
